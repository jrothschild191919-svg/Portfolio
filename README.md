# Jaden Rothschild | Data Science Portfolio

Static site for GitHub Pages. Upload the **contents** of this folder to the root of your GitHub repository, then enable GitHub Pages from `main` / root.

## New case-study resources
- Seven supplied research documents are hosted in `reports/` (including the Axaitech presentation and NFL fourth-down poster).
- Project visual previews are in `assets/`.
- Three external UVA Basketball scouting dashboards are linked on the scouting case study. **Verify you have approval to publish these links and related information.**
- World Cup simulation chart is displayed from your supplied image; no full report/code was supplied.
- Project code repositories remain placeholders.

## Updating entries
Edit `assets/projects.js`. Each project has fields for `report`, `visual`, `code`, and optional `links`. Paths in `report` and `visual` are relative to `projects/project.html`. `assets/site.js` strips `../` when rendering cover images on the homepage.

## Publishing
1. Unzip the site.
2. Upload all unzipped files and directories to the GitHub Pages repository (not the zip).
3. Commit changes; wait for the Pages build.
4. Test report links and mobile layout.
